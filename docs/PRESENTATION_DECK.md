## Slide 2: The Core Problem in Autonomous Wallets (0:45 - 1:45)
- **Problem 1: The Custody Paradox**:
  - Full autonomy = prompt injection vulnerabilities, hallucinated transactions, and drained treasuries.
  - Human-in-the-loop for every micro-tx = loss of autonomous execution benefits.
- **Problem 2: State Divergence & Race Conditions**:
  - Unsynchronized concurrent AI agents can double-spend budgets before limits update.
- **Problem 3: Client-Side Security Fallacies**:
  - Most hackathon prototypes store private keys in frontend storage or trust client-side validation.

## Slide 4: Key Technical Innovations (2:45 - 3:45)
1. **Cryptographic Binding Hash**: Pre-flight simulation binds transaction parameters via SHA-256. Any parameter tampering before authorization triggers HTTP 409 Conflict.
2. **Atomic Row-Level Spending Serialization**: Database locks serialize concurrent agent requests (verified under 10 simultaneous parallel requests).
3. **Canonical Idempotency Engine**: Key-order independent payload hashing prevents double-broadcast on network retries.
4. **Honest Receipt Verification**: A submitted hash alone never marks a transaction "confirmed"; receipts are queried for `status === 'success'`.
